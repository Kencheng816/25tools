## 5. 需你決定（(c) 項目）
1. **匯出渲染路徑**：B/祖 匯出前重跑 `refreshTemplateFromBatchRecord`（二次套版）；A 用唯讀快照。統一 core 兩條路徑都保留（旗標 `export.renderPath`），還是以黃金樣本驗證 B 走 A 路徑是否零差異後合一？
2. **OM wave1 → wave2**：資料面 w2 是 w1 超集，但 w2 layout 有 3 處會改 w1 既有輸入的像素（新增 priceRules、單品掉圖修正、價格收框＋82%）。用 w2 取代並**重做 w1 黃金樣本**，或用 `omWaveProfile` 旗標保留 w1 行為？
3. **KV `TextBaselineModel.prepareTemplate`**：唯一不呼叫的工具，補上會改文字基線。保留 KV 舊行為（旗標 `templates.textBaselinePrepare=false`）？
4. **smart-asset-manager 三實作**（A registry／B session／KV localStorage）：三檔並存由 profile 選載？MS 精簡版是否可由正式BN 版取代？
5. **HistoryManager**：A transaction 模型功能為超集，但 `attachExtra` 語意與 B 不同。統一採 A＋B 相容 shim？
6. **正式BN / 暖身BN 同名 family**（HBN、DD Card、POPUP）rules 與 `warmup-placement-presets` 27 個同名 key 內容不同 → 必須命名空間隔離，由「工具分類」決定載入哪組（與 D1 自動偵測相容：偵測到 BN 工單後仍需分「正式/暖身」，可由分頁名 `BN 正式`/`BN 暖身` 判斷）。
7. `fetchRouteTemplate` 後處理三版本應與 `loadTemplateFolder` 前處理統一（同一份 JSON 兩條載入路徑）。
8. `sheetTemplateRoute` 多兩鍵（`templateFile/multiOutput`）— 取決於黃金 session.json 是否逐位元比對（建議：JSON diff 忽略此二鍵）。
9. 文字互動縮放三種換算（`applyTypographyScale` vs `fontSizePx×factor` vs ＋SPTextStandard）黃金樣本無互動覆蓋不到 → 是否補互動回歸案例？
